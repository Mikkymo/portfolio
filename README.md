# Chukwuemeka Ogo · Data Analyst portfolio

[Visit the portfolio](https://mikkymo.github.io/portfolio/) · [LinkedIn](https://www.linkedin.com/in/ogochukwuemeka/)

A static GitHub Pages portfolio presenting six case studies across CRM, sales, loan recovery, supply chain, telecom churn and healthcare data. Each project card links to its own repository for the analysis files and documentation.

## Maintain the site

- Edit `index.html` for the introduction, project summaries and contact details.
- Keep image assets in `images/`; update their `src` references in `index.html` if renamed.
- `resume.pdf` is the current Chukwuemeka Ogo draft; an earlier copy is retained in `archive/` for comparison. Verify career history and certifications before publishing.
- Keep the HTML5 UP licence and template attribution in place (`LICENSE.txt`, `README.txt`).
- To preview locally, serve this directory with `python -m http.server 8000` and open `http://localhost:8000/`.
